GitHub Pages 部署指南

本網頁為單一檔案架構（Single-File App），非常適合直接部署至 GitHub Pages！請依循下列步驟操作：

1

建立 GitHub Repository

在 GitHub 建立一個新的公開儲存庫（Repository），例如命名為 youbike-map。

2

儲存檔案並命名為 index.html

將此網頁完整程式碼儲存為 index.html，並上傳至你的 GitHub Repository 根目錄下。

3

啟用 GitHub Pages

  • 進入你的 Repository 設定頁面（Settings）。
  • 點擊左側導覽選單中的 Pages。
  • 在 Build and deployment 區塊的 Branch 設定中，選擇 main（或 master）與 / (root)。
  • 點擊 Save 儲存。
4

完成與預覽

等待數十秒後重新整理設定頁面，上方即會出現你的專屬線上網址（例如 https://your-username.github.io/youbike-map/），點擊即可在任何裝置上瀏覽即時 YouBike 地圖！
